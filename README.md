# MeuFinanceiro

Gestor financeiro pessoal e familiar, open-source e autohospedado, voltado ao contexto brasileiro.

> Projeto em fase de fundação. A arquitetura, o modelo de domínio e o processo de contribuição estão sendo definidos antes do início das funcionalidades.

## Princípios

- Execução local por Docker, com acesso web por PWA.
- Dados financeiros sob controle do usuário.
- Funcionamento sem integração bancária obrigatória.
- Open Finance opcional por adaptadores, começando pela Pluggy.
- Nenhuma iniciação ou execução de transações financeiras.
- Planejamento e colaboração organizados por GitHub Issues e Pull Requests.

## Estado

A base técnica e documental está em preparação. Issues de implementação serão abertas progressivamente, com dependências e critérios de aceite explícitos.
